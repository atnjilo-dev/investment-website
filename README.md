# Aurvon — Version 2.0

Premium front-end concept for an investment platform.

## Files
- `index.html` — public landing page
- `styles.css` — responsive black/gold visual system
- `login.html` — investor portal entry screen

## Important
This build is a front-end prototype. Authentication, real investor records, payments, portfolio accounting, KYC/AML, audit logs, permissions, and regulatory controls are **not implemented**.

Do not represent illustrative figures or unavailable investment products as real. Connect only legally permitted and appropriately licensed services before taking real client funds.
